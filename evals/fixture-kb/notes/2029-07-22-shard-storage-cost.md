# Index shard storage cost

> FICTIONAL FIXTURE. Nothing here describes a real system.

**STALE AND PROVISIONAL — written 2029-07-22, review date 2030-01-22 has passed.**

## Estimate

Storage worked out to roughly **18 currency units per shard per month** at the index
size of the day.

## Caveats, which are most of the value of this note

- It is a single month's bill divided by the shard count. It is not a rate card and
  it was never checked against one.
- Index size has grown since, and the figure scales with size, not with shard count.
- It was gathered to answer one question — whether a shard split was affordable —
  and it answered it. It was never meant to survive as a planning number.
